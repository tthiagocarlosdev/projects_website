Verificação do Node.js

Para identificar o computador, esta página utiliza um pequeno serviço local executado pelo Node.js.

Antes de realizar o teste, verifique se o Node.js está instalado no computador.

  1. Abra o Prompt de Comando (CMD) do Windows.
  2. Digite o comando abaixo:
node -v

Pressione Enter.

Se o Node.js estiver instalado, será exibida uma versão, por exemplo:

v24.21.0

Caso apareça uma mensagem informando que "node não é reconhecido como um comando", o Node.js não está instalado ou não está configurado no PATH do Windows.
